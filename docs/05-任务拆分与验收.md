# 05 · 任务拆分与验收（Cursor 任务入口）

> 每个任务一条 PR，分支 `feature/<任务号>-<kebab>`。任务号即 ticket。
> 任务字段：**依赖** / **产出** / **验收**。验收项必须能被测试名或可复现步骤证明。
> 旧代码引用路径见 `01` 文档开头的缩写约定。
