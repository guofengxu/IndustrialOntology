# 03 · 前端设计（`wp-web`）

> 栈：React 18 + TypeScript 5 + Vite 6 + Ant Design 5 + TanStack Query + zustand + react-router 6 + react-i18next + CodeMirror 6 + flexlayout-react。

## 2. 路由（兼容旧 URL）

## 4. 透视图布局模型

后端原样保存 widgetmap JSON：

```json
{"@type":"ParentNode","direction":"row","children":[
  {"weight":0.3,"node":{"@type":"LeafNode","properties":{"portlet":{"@type":"String","value":"portlets.ClassHierarchy"}}}},
  …]}
```

前端 `features/perspectives/layoutModel.ts`：

- `toFlexLayout(widgetmapJson) → IJsonModel`：`ParentNode(row)` → `row`，`ParentNode(column)` → 嵌套 `row` + 垂直；权重 → `weight`；`LeafNode` → `tabset` 含一个 `tab{component: portletId, id: uuid}`；未知 portlet id 也保留。
- `fromFlexLayout(IJsonModel) → widgetmapJson`：逆变换，保证 `fromFlexLayout(toFlexLayout(x))` 与 `x` 结构等价（属性测试覆盖 8 个内置布局 + 随机树）。
- 保存策略：布局变更防抖 1 s 后 `PUT .../layout`（旧行为即时保存）。
- 空白透视图：显示"添加视图"按钮 → `PortletChooser`（按分组列出注册表中可用 Portlet）。

## 5. 关键组件

| 组件 | 实现要点 |
|---|---|
| `EntityTree`（层级） | AntD `Tree` 虚拟滚动 + `loadData` 懒加载子节点；节点渲染：显示名、标签色点、废弃删除线；拖拽 → `POST .../move`；右键菜单：创建、删除、编辑标签、移动到父级、合并、设置注解值、关注、剪枝到根、清除剪枝、显示 IRI、刷新；通过 SSE `EntityHierarchyChanged` 局部刷新 |
| `FrameEditor`（5 种） | 上方父类/类型列表（`EntityPicker` 多值），下方 `PropertyValueTable`（AntD Table 可编辑行：属性 + 值 + 语言/数据类型）；编辑态保存 `pristine` 帧，提交 `PUT {from,to}`；409 时弹窗提示并重载 |
| `PrimitiveDataInput` | 一个输入框接受实体名/字面量/IRI：输入时调 `lookup` 补全，回车解析为 `{@type, iri}` 或字面量；新实体策略由 crud-settings 决定（弹出"创建新实体？"）；语言标签下拉 |
| `ManchesterEditor` | CodeMirror 6；自定义语言（关键字高亮：`Class:`、`SubClassOf:`、`EquivalentTo:`、`some`、`only`、`and`…）；`check` 防抖 500 ms 显示错误；`completions` 接 `autocompletion` 扩展；保存带提交信息 |
| `FormRuntime` | 按 `FormDescriptor` 渲染：Text、Number、SingleChoice（Combo/Radio/SegmentedButton）、MultiChoice（Checkbox/List）、EntityName、Image、Grid（分页、排序、过滤、列显隐）、SubForm（嵌套）；可重复字段；语言图编辑；提交 `PUT .../entities/forms` |
| `SearchModal` | 顶栏快捷键 `Ctrl+K`；输入 → `POST entities/search`；语言标签过滤、实体类型筛选、匹配高亮；选中 → 更新 `selection` |
| `CriteriaBuilder` | 组合条件编辑器，首期支持：实体类型、注解值包含/正则、语言标签、子类/实例、废弃状态、标签、IRI 前缀；其余条件以 JSON 编辑器兜底 |
| `ChangeList` + `DiffView` | 分页变更卡片：作者、时间、说明、摘要；展开显示公理 diff（Manchester 文本，增绿删红）；回滚按钮；下载该修订 |
| `DiscussionThread` | 线程列表、回复、编辑、删除、关闭/打开；编辑器 CodeMirror 6 + `@user` 与 `#entity` 补全；`renderedBody` 显示 |
| `SharingDialog` | 用户补全 + 权限下拉；链接共享开关 |
| `SettingsPages` | 通用 `SettingsSection` 容器：主设置、新实体设置、默认语言、显示名、Webhook；导入/导出 JSON |
| `ProjectList` | 三 Tab；卡片操作：打开、新窗口打开、下载、回收站；新建项目向导（可选上传 OWL 文件 → `/api/v1/uploads`） |
| `TopBar` | 回首页、项目菜单（设置、标签、表单、前缀、导出/导入设置）、分享按钮、显示语言切换、搜索、帮助、用户菜单（API Key、登出） |

## 6. 实时与缓存

- `api/sse.ts`：每个打开的项目一个 `EventSource(/api/v1/projects/{id}/events/stream?since=tag)`；记录最后 `id`（eventTag）；断线用 `since` 重连；Bearer 通过短期 `?token=` 查询参数或 Cookie 方案（二选一，在 P1 的 SSE 任务里定：优先使用服务端签发的 5 分钟一次性 stream ticket：`POST /api/v1/projects/{id}/events/ticket`）。
- 事件 → 失效策略（`features/events/invalidation.ts`）：

| 事件 | 失效的 query key |
|---|---|
| `ClassFrameChanged` 等帧事件 | `['project', id, 'frames', *, iri]`、`['project', id, 'forms-data', iri]` |
| `EntityHierarchyChanged` | 树局部更新（不整树失效） |
| `BrowserTextChanged` | `['project', id, 'rendering', iri]` + 树节点标签 |
| `CommentPosted/Updated`、`DiscussionThread*` | `['project', id, 'threads', iri]`、`commented-entities` |
| `EntityTagsChanged`、`ProjectTagsChanged` | tags 相关 |
| `ProjectChanged` | `['project', id, 'changes']`、`revisions/head`、`feed` |
| `PermissionsChanged` | `['project', id, 'permissions']` |
| `ProjectSettingsChanged`、`DisplayNameSettingsChanged` | settings、rendering 全部 |

- 写操作返回的 `eventTag`：若 SSE 已收到 ≥ 该 tag，无需额外失效。

## 7. 认证流程

1. `oidc-client-ts` 以 PKCE 登录 Keycloak；token 存内存（刷新用 refresh token，`silent renew`）。
2. `client.ts` 自动附加 `Authorization: Bearer`；401 → 触发登录；403 → Problem 提示。
3. dev 模式支持 `VITE_API_KEY` 走 `ApiKey` 头，方便无 Keycloak 调试。
4. `/api/v1/me` 返回的 `applicationActions` 决定顶栏管理入口显隐；项目内按钮显隐用 `permissions` 查询。

## 8. i18n

- 命名空间按 feature；默认 `zh-CN`，回退 `en`。
- 旧 `Messages.java`（约 287 条）与 `FormsMessages.java`（42 条）的英文文案作为 `en` 初始值一次性导入（脚本 `tools/extract-gwt-messages.ts` 解析 `@DefaultMessage`），中文由人工翻译。
- 实体显示名的多语言来自服务端（`displayNameSettings`），与 UI 语言无关。

## 9. 构建与交付

- `pnpm build` → `dist/`；`wp-server` 的 Maven `frontend-maven-plugin` 在 `prepare-package` 阶段执行 `pnpm install --frozen-lockfile && pnpm build` 并把 `dist` 复制到 `wp-server/target/classes/static/`（CI 可用 `-Dskip.web` 跳过）。
- SPA 回退：`wp-api` 的 `SpaForwardController` 把非 `/api`、`/data`、`/download`、`/registry`、`/actuator`、`/v3`、`/swagger-ui` 的路径转发到 `index.html`。
- 开发：Vite 代理，前后端分跑。
